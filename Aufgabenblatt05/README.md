# Aufgabenblatt 05 - Written Solutions (2D/3D Transformations)

This sheet was submitted as written answers only: `Aufgabenblatt05.pdf` contains the
worked solutions to the affine transformation and matrix exercises (scaling/translation,
rotation including rotation about an arbitrary point, shear, chained matrices and 3D
rotation matrices).

There is no code and no CMake project for this sheet - see the root README for the sheets
that contain programs.
