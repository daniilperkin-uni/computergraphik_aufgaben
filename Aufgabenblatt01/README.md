# Aufgabenblatt 01 - C++ Fundamentals

This assignment introduces fundamental concepts of C++ programming. It covers:

*   **Basic C++ Syntax:** Simple functions and program structure.
*   **Standard Template Library (STL):** Usage of basic STL containers and algorithms.
*   **Custom Classes and RAII:** Implementation of custom data structures and resource management using RAII (Resource Acquisition Is Initialization) principles.

## Build and Run

To build and run the solutions for "Aufgabenblatt 01", follow the general build instructions in the main `README.md` from the project root. You can navigate into the `Aufgabenblatt01/aufgaben_blatt_01/` directory to build it specifically.

**Example Build (from project root):**
```bash
# From the project root directory
mkdir build_ab01
cd build_ab01
cmake ../Aufgabenblatt01/aufgaben_blatt_01/
cmake --build .
```
Executables will be found in `build_ab01` (e.g., `aufgabe_1`, `aufgabe_2`, `aufgabe_3`, `aufgabe_4`).
